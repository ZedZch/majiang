# 🀄 雀圣兵法 · 川渝麻将高阶推演教学系统 (换三张·血战到底)

> **专为熟悉麻将基本规则、希望进阶掌握「读牌算牌、手牌镜像反推、听牌预测、避炮控张」的高级选手打造的深度战术推演教练。**

---

## 🌟 项目简介

市面上大多数麻将软件仅停留在“教新手胡牌规则”或“简单出牌助手”，而**《雀圣兵法》**针对的是具备基础牌理、但常在实战中因“不知道别人要胡什么”、“随意出中张被清一色抓炮”、“不知何时该弃胡防守”而输牌的进阶玩家。

本项目采用纯前端现代架构（HTML5 + CSS3 + 原生 JavaScript），实现了完整的**重庆/四川地区经典“换三张·血战到底”**规则体系，并内建一套**严谨遵循博弈论、牌效向听数、牌河读牌心理学及壁筋理论**的高阶推演引擎。

在每一手切牌时，玩家均可点击 **「💡 战术推演 (AI思考过程)」**，查看宛如大师亲授的**详尽四步推导脉络与数学概率分析**，切实提高实战胜率。

## 🚀 核心系统与功能亮点

### 1. 完整逼真的川渝换三张·血战到底对局
- **全套108张纯筒条万牌池**：无风字牌，原汁原味川渝麻将。
- **换三张阶段（Swap-3）**：支持自主挑选 3 张同花色牌交换，支持一键查看 AI 大师换牌推荐（留长弃短，做大牌底子）。
- **定缺门阶段（Dingque）**：定缺万/条/筒，全流程强约束（手中有定缺门牌时强制必须优先打掉，杜绝违规）。
- **血战到底（Blood Battle）**：一家胡牌并不结束牌局，胡牌者展示已胡金标，其余选手继续战斗，直到 3 家胡牌或摸完牌山查大叫、查花猪。
- **免依赖纯净 Web Audio 音频引擎**：利用浏览器原生 Web Audio API 动态合成骨牌碰撞、落桌、摸牌、碰、杠、胡音效，无需下载臃肿音频文件。

### 2. 高阶读牌与手牌镜像反推引擎 (Hand Reading Engine)
- **换三张线索逆推**：
  - 记录各家换出花色与换入花色。
  - 推断逻辑：选手换出的花色通常起手不超过 3-4 张；而其换入的花色手牌骤增 3 张，极大概率成为主战花色或清一色候选。
- **定缺门与“变步点”抓听**：
  - 监控各家何时打完定缺牌。
  - 捕捉对手从打定缺牌转为**打第一张非缺门牌（变步点 Transition Point）**的巡目，判定其进入一向听或听牌阶段。
- **对手牌型定性与威胁评级**：
  - **清一色（4-8番极危）**：结合副露花色与舍牌纯净度，精准识别专攻清一色的危险对手。
  - **对对胡 / 金钩钓（2-4番）**：识别多副碰牌与单调听牌。
  - **门清七对（4番）**：识别无副露且舍牌稀疏的中张保留行为。

### 3. 防点炮精算体系 (Defense & Deal-In Avoidance)
- **绝对现物 (Genbutsu)**：对手自己打过的牌、本巡刚打出的同门牌，100% 免疫荣和。
- **定缺门免疫**：打入对手定缺门的牌对该对手放炮率为绝对 0%。
- **筋牌理论 (Suji 1-4-7, 2-5-8, 3-6-9)**：
  - 严谨拆解**真筋**（如打过4，1为真筋）与**半筋**（如打过4，7仍需防56待47）。
- **壁牌理论 (Kabe / No-Chance)**：
  - 当某张牌（如7条）全场4张全部现明时，对手无法持有 7-8 听 6-9，推导出 8-9 的结构性阻断安全通道。
- **全手牌综合危险度热力标签**：
  - 实时在手牌右上角标注放炮危险度（绿/黄/橙/红），危险原因一目了然。

### 4. 攻守平衡期望值 (EV) 决策模型
- 拒绝盲目追求牌效！在面对他人清一色听牌威胁时，系统会计算：
  $$\text{Net EV} = \text{Speed Score} - \text{DealIn Risk} \times \text{Opponent Fan} \times \text{Defense Weight}$$
- 向听数落后或对手番数过大时，果断给出**「弃胡防守 / 拆张避炮」**的大师级建议。

### 5. 高阶战术残局推演训练 (Scenarios Trainer)
- 内置经典高难度残局：
  1. *生死拆张·规避下家清一色满贯炮*
  2. *筋牌与壁牌的安全度拆解*
- 玩家可随时一键加载残局，进入实战环境拆解思考。

## 💻 运行与体验方法

本项目没有任何第三方框架或打包构建步骤，也不需要复杂的 npm 安装：

1. **直接打开**：双击项目根目录下的 `index.html`，即可在任何现代浏览器（Chrome、Edge、Safari、Firefox）中流畅体验。
2. **本地静态服务器（可选）**：
   ```bash

   python -m http.server 8080
   # 浏览器访问 http://localhost:8080
   ```

## 📖 雀圣实战兵法核心笔记摘要

- **法则一【留长弃短，做大不做小】**：川渝麻将中平胡（1番）赢分极少，换三张后只要一门牌张数达到8张以上，应果断舍弃杂色奔向清一色（4番起步）。
- **法则二【变步手切即警报】**：观察对手何时停止打定缺牌并打出第一张非缺门牌。此时往往已经一向听，紧接着打出的生张中张极度危险。
- **法则三【宁弃胡，不点大】**：血战到底的核心是控制下行方差。一旦发现场上有两家以上做大牌或已听牌，自己若仅为小牌甚至未入听，必须坚决弃胡，选择跟打绝对现物或对手定缺牌。
- **法则四【定缺牌早打中张】**：定缺门内的 4、5、6 等中张必须在开局前 3 巡内坚决切出，拖到中盘之后再打定缺中张极易沦为送命炮牌。
